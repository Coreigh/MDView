# MDView
A light versatile markdown viewer with basic editing and export features.
> **Organize your files your way, connect them when you need to.**

mdview is a single-page, client-side Markdown editor and previewer. No build
step, no server dependencies, no external network requests on load. Everything
is plain HTML, CSS, and JavaScript served from a single directory.

**Current version:** v15.3.0
